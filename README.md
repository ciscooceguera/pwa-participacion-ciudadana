# PWA de Participación Ciudadana

Primer incremento funcional del MVP de una aplicación web progresiva para documentar problemas urbanos.

## Historia técnica seleccionada

**HT-001 - Implementar el Formulario de Reporte**

El incremento permitirá capturar:

- categoría del problema;
- descripción;
- evidencia fotográfica;
- ubicación opcional.

## Tecnologías

- HTML5
- CSS3
- JavaScript vanilla
- APIs estándar del navegador
